QUICK GUIDE

Header ZCZC B1 B2 B3B4: B1 = transmitting station (A–X) · B2 = message type (A–Z) · B3B4 = serial number (00 = must always be printed).
Keys: LIST = message list · ENT = select / open · MENU/ESC = menu or back · ▲▼ move · ◀▶ select · PRINT = print shown message · DIM ± = brightness.
Cannot be rejected: A (navigational warnings), B (meteorological warnings), D (SAR / distress / piracy), L (additional nav warnings).
Keyboard: arrows, Enter = ENT, Esc = MENU, L = LIST, P = PRINT.

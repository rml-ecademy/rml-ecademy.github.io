QUICK GUIDE

Depth references: DBT = depth below transducer · DBS = DBT + transducer draft · DBK = DBT − keel offset (keel below transducer). DRAFT key cycles the reference shown.
Alarm is referenced BELOW TRANSDUCER: shallow alarm = required UKC + (deepest draft − transducer depth).
RANGE 1–8 = 5 / 10 / 20 / 50 / 100 / 200 / 500 / 800 m · AUTO = auto range · GAIN 0–10: too low → bottom lost, too high → noise / false lock.
200 kHz = sharp picture, shallow water (≈ <150 m) · 50 kHz = deep water (to 800 m).
MODE: NAV · DBS (full echogram, depth below surface) · HISTORY · LOGBOOK · OS DATA · HELP · MENU. In MENU: ▼ AUTO / ▲ COLOR select, − / + change (hold to repeat).
Knobs: click left / right half or use the mouse wheel.

RULE — APPLYING GYRO ERROR

Gyro error = Gyro − True.
Gyro reads more than true → error HIGH → subtract to get true.
Gyro reads less than true → error LOW → add to get true.
True → Gyro: do the opposite (HIGH add · LOW subtract). Check gyro error every watch and after large alterations of course; record it in the compass error book.

TRAINING EXERCISES

FORMULAS

Azimuth (from LHA, Dec, Lat):
tan Z = sin LHA ÷ (cos Lat · tan Dec − sin Lat · cos LHA)
LHA > 180° → sun EAST: count Z from N towards E (or use the ABC tables). Zn = true azimuth 000–360.
Amplitude: sin A = sin Dec ÷ cos Lat
Rising → E, setting → W; named N/S same as Dec. Dec S, rising: Zn = 090° + A. Take the bearing when the sun's lower limb is about half a diameter above the visible horizon (centre on the celestial horizon).

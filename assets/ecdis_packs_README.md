# ECDIS training chart packs (world)
`ecdis_<region>_chart.gz` (cells, land, contours, features, AIS, notices, ENC list) + `ecdis_<region>_depth.gz` (delta-encoded uint16 depth grids), listed in `ecdis_packs.json`.
Generated by `tools/gen_pack.py` from open data: OpenStreetMap coastline via geo-maps (ODbL), Natural Earth bathymetry, ports and names (public domain).
Depths, lights, buoys, fairways, traffic and notices are SIMULATED for training. NOT FOR NAVIGATION.
